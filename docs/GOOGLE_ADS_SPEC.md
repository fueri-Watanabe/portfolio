# Google広告 運用設定仕様書

## 1. キャンペーン基本設定
- **目的**: コンバージョン獲得（`fueri_contact_submit` / GA4 `contact_submit` 連携）
- **キャンペーン種別**: 検索キャンペーン
- **ターゲット地域**: 日本全国
- **配信ネットワーク**: Googleディスプレイネットワークは無効（検索結果のみ）
- **入札戦略**: コンバージョン数の最大化（初期Target CPAなし）
- **初期日額予算**: 1,000円〜2,000円/日（月額約30,000円〜60,000円）

---

- **目標・コンセプト**: 高意欲な開発見積もり・費用検索層の獲得
- **ランディングページ (LP)**: `https://fueri.jp/diagnostic`（無料見積もり診断ツール）

## 3. 除外キーワード（ネガティブキーワード設定要件）
無駄な広告費消化を防ぐため、以下のキーワード群を除外キーワードリストに登録する：
`無料, フリー, 勉強, 独学, 作り方, チュートリアル, 入門, サンプルコード, コード, コピペ, 初心者, 求人, バイト, 転職, 年収, 副業, 案件募集, とは, 仕組み, 本, 参考書, qiita, zenn`
